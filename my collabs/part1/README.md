## Краткие замечания

`SMOTE` и `BorderlineSMOTE` помогают работать с дисбалансом классов, но не делают редкие классы автоматически простыми. Если реальных примеров мало, результат по таким отказам обычно менее стабильный.

`StratifiedKFold` дает более спокойную картину, потому что данные перемешиваются. `TimeSeriesSplit` строже: обучение идет на прошлом, проверка на будущем. Для временных данных такая проверка полезнее.

`PCA` нужен для просмотра структуры данных. Если классы на 2D-графике пересекаются, значит простого визуального разделения нет и нужна модель по исходным признакам.
